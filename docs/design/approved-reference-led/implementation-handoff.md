# LibreRing Prototype Handoff

Read `DESIGN.md`, `brand-spec.md`, and `design-contract.md` before editing the artifact.

- Build one self-contained semantic HTML file with no remote fonts or images.
- Bind the six OKLch tokens verbatim. Use Helvetica Neue/Nimbus Sans fallbacks.
- Keep screens at a canonical 390×844 ratio with 24 px content insets and 44 px minimum targets.
- Use original inline SVG/CSS for rings, heatmaps, and charts. Coral is data, not decoration.
- Keep stats/recovery separate from the 2×2 metrics grid.
- Use opaque flat cards (14–18 px radius), no gradients, blur, glow, or heavy shadow.
- Provide a gallery plus a focused clickable mode that shares the same screen components.
- Verify keyboard flow, labels, focus, reduced motion, no horizontal overflow, and all twelve required states.

The first artifact should prove that LibreRing can feel premium through typography, whitespace, and evidence discipline alone—and that an unsupported reading can be as resolved as a positive result.
