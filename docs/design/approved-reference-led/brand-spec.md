Observed/provided visual-language rules:

1. Light, oversized numerals create the primary hierarchy.
2. Warm paper and flat mineral-grey cards carry almost all pixels.
3. Coral is reserved for meaningful data encoding and rare selection feedback.
4. Mobile screens isolate one reading or decision with unusually generous whitespace.
5. Navigation is compact, floating, opaque, and nearly decoration-free.

System summary: LibreRing is a warm, typographic, evidence-first mobile system where quiet whitespace and one coral data signal replace decorative UI.
