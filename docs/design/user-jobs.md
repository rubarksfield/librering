# User jobs and flows

## Primary audience

An adult who chose an inexpensive COLMI R12 and wants a calm, private way to
understand sleep, recovery context, movement, and device reliability without an
account. They may swim or strength-train, may use Apple Health/Health Connect,
and may want technical detail—but not before the daily answer.

## Jobs

| Situation | Job | Done when |
| --- | --- | --- |
| First use | Pair without creating an account and understand what the ring can/cannot do | device identity is verified; permissions are explained; first sync state is visible |
| Morning | Know how sleep went and whether today looks normal | Daily Signal, three domains, confidence, and main reason are understood in five seconds |
| Incomplete night | Understand why data is absent without feeling blamed | no false score; missing window, preserved data, and next action shown |
| Swim | Record a swim despite no ring detection | duration/effort/source saved; Movement recognises it; no invented laps/HR |
| Trend check | Answer whether sleep is improving over 30 days | direction, coverage, baseline change, and contributing pattern visible within three taps |
| Device issue | Recover from stale sync safely | last success, battery, error, bounded retry, diagnostic/export option shown |
| Data ownership | Export or delete data locally | preview, format/scope, completion proof, and separate Cycle deletion are clear |
| Cycle Context | Opt in without affecting core use | local consent, modes, limitations, separate deletion, hidden notifications understood |

## Eight prototype journeys

1. Welcome → privacy promise → capability limits → pair → first sync → Today.
2. Today → Sleep Explain → pulse trend Inspect → back.
3. Today incomplete card → data explanation → device fit/battery action.
4. Today → Log → Swim → duration/effort → saved Movement explanation.
5. Trends → Sleep → 30 days → coverage/baseline detail.
6. Device control → stale sync → retry → recovered state.
7. You → Data → export preview → local export complete.
8. You → Cycle Context opt-in → choose Track cycle → separate delete preview.

## Five-second test

Without coaching, the opening screen must communicate: “last night was limited
mainly by duration; Recovery is moderate-confidence; ring synced recently with
adequate battery.” If a user reads stage percentages, raw pulse, or settings first,
the hierarchy failed.

## Three-tap test

From Today, each must be reachable in three taps: last night's pulse trend,
reason Recovery changed, 30-day sleep direction, log swim, sync diagnostics,
export, and Cycle Context deletion.
